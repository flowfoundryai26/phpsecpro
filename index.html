Is Your PHP Version Supported?

Unsupported PHP releases stop receiving security patches — and automated bots actively scan for exactly those versions. Outdated PHP plus abandoned plugins is a common entry point for hacked websites. You can verify current support windows on the official PHP site.

PHP 7.4 — End of life Nov 2022 PHP 8.0 — End of life Nov 2023 PHP 8.1 — Security-only
Support status changes over time — always confirm at php.net/supported-versions.php.

Illustrative Security Scenarios

Example Engagement Scenarios

Illustrative Security Scenario — these are composites of the kind of work we perform. They are not customer testimonials or completed case studies.
Illustrative Security ScenarioWooCommerce · PHP 7.2

WooCommerce store flagged by Safe Browsing

The Situation

A retailer is notified that the store has been flagged by Google Safe Browsing. Traffic drops sharply and checkout errors begin appearing.

How We Would Approach This Scenario
  • Isolate the site and capture a forensic copy before changes
  • Identify and remove suspicious code and unauthorized accounts
  • Upgrade PHP, then guide blacklist reconsideration
Possible OutcomeThe store is cleaned, the blacklist removal is guided, and the site is returned to normal traffic — subject to scope and confirmation.
Illustrative Security ScenarioLaravel · Cloud VM

Laravel app with an exposed .env file

The Situation

A B2B dashboard is deployed with APP_DEBUG enabled and a publicly reachable .env file that may contain database and mail API credentials.

How We Would Approach This Scenario
  • Restrict access to config, logs and hidden files
  • Rotate all potentially exposed credentials
  • Add WAF rules, CSP/HSTS headers, and a deploy checklist
Possible OutcomeExposure is closed and credentials rotated before misuse, with a documented deployment checklist.
Illustrative Security ScenarioCustom PHP · Shared Hosting

Legacy custom CMS repeatedly defaced

The Situation

A regional news portal runs a hand-built PHP 5.4 CMS. Defacements recur every few months despite file restorations.

How We Would Approach This Scenario
  • Assess and migrate to a supported PHP version
  • Review authentication and database access patterns
  • Recommend an ongoing maintenance & monitoring plan
Possible OutcomeA stable, supported stack with monitoring and a maintenance cadence — reducing recurrence risk.
